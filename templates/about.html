ℹ️ О проекте

«Реставратор фасадов» — нейросеть, которая восстанавливает облик зданий по фрагментам фотографий и текстовым описаниям.

Как это работает

  • 🔍 Ищет референсы в Википедии про выбранный стиль
  • 🔑 Извлекает ключевые слова из вашего описания
  • 📁 Использует примеры из датасета как референсы
  • 🧠 Обучается на ваших оценках 👍/👎

Движки генерации

  • ⚡ Flux / Turbo (Pollinations) — быстрые, без ключа
  • 🎨 Stable Diffusion (AI Horde) — запасной, для фрагментов

Датасет

В папке dataset/ лежат примеры домов по стилям. Нейросеть читает описания из info.txt и использует их при генерации, чтобы рисовать точнее.

Технологии

Python 3.13 · Flask · HTML5 · CSS3 · Без JavaScript · Работает без VPN
